# Python Conditions Examples

This repository contains beginner‑friendly Python programs that demonstrate the use of conditional statements.  
It includes clear examples of `if`, `if-else`, and `if-elif-else` structures.

## Features
- Age eligibility check (vote, drive)
- Grading system based on marks
- Positive/Negative number check
- Even/Odd number check
- Divisibility by 5
- Traffic light rules
- Temperature classification
